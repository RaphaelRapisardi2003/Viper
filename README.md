## 📘 Introdução
Site de e-commerce fictício de moda feminina, desenvolvido como projeto de estudo de front-end com foco em HTML semântico e CSS moderno.

## 📖 Descrição do Projeto
A **Viper** é uma loja virtual de roupas, acessórios e joias femininas. O projeto simula a interface de um e-commerce real, com barra de navegação por categorias, banner de destaque, barra de pesquisa e seção de produtos.

## 🔧 Funcionalidades e Demonstração da Aplicação

- 🧭 Barra de navegação com categorias (New, Tendências, Marcas, Bolsas, Roupas, Sapatos, Acessórios, Joias, Sale)
- 🔍 Barra de pesquisa integrada no header com foco visual
- 🖼️ Banner duplo de destaque com efeito de zoom ao passar o mouse
- 📱 Layout responsivo para desktop, tablet e mobile

## 🤖 Técnicas e tecnologias utilizadas

- `HTML5` — estrutura semântica com `header`, `nav`, `div` e atributos de acessibilidade (`lang`, `alt`, `viewport`)
- `CSS3` — Flexbox, transições, `object-fit`, media queries para responsividade completa
- `Google Fonts` — Material Symbols Outlined para ícones
